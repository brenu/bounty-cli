# Bounty CLI

A Go-based command-line interface for automating bug bounty recon and vulnerability discovery, specifically integrated with the Intigriti Researcher API.

## Core Capabilities
- Automated program scope retrieval.
- Subdomain enumeration (via external tools).
- Live host identification.
- Vulnerability scanning (via Nuclei).
- Deduplication and reporting of findings.
- Automated report generation in the `reports/` folder with program-based naming and versioning (e.g., `Program_Name.md`, `Program_Name_v1.md`).
